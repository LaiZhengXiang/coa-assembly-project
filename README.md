# Computer Organization and Architecture (COA) Assembly Project

> A low-level assembly language program developed in Visual Studio, demonstrating direct hardware and memory manipulation.

## 📋 About The Project
This project was written in x86/MASM Assembly to demonstrate an understanding of computer architecture, memory management, and register-level operations. The program is designed to [一句话解释你的 main.asm 是做什么的，例如：perform basic arithmetic operations and manipulate string inputs at the memory level].

## 🛠️ Built With
* **Language:** x86 Assembly (MASM)
* **IDE:** Microsoft Visual Studio
* **Architecture:** x86 / Windows

## ✨ Key Concepts Demonstrated
* **Register Manipulation:** Efficient use of CPU registers (e.g., EAX, EBX, ECX) for data processing.
* **Memory Management:** Direct memory addressing and stack operations (PUSH/POP).
* **Control Flow:** Low-level implementation of loops and conditional jumps (JMP, JZ, JNZ).
* **System Calls:** Interrupt handling / invoking system services for input and output.
